# Bar Zenit Pub — Sito Web

Menu digitale ufficiale del **Bar Zenit Pub** di Ateleta (AQ).  
Burger From 1996.

## Stack
- HTML/CSS/JS vanilla — zero dipendenze, zero build step
- Font: [Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed) via Google Fonts
- Deploy: [Vercel](https://vercel.com)

## Struttura
```
sito-zenit/
├── index.html       # Sito completo (CSS + JS inline)
├── logo.png         # Logo principale
└── README.md
```

## Sezioni menu
- Sandwich
- Burger
- Snack
- Fries
- Tex-Mex
- Cocktail
- Bevande
- Birre

## Dev locale
Apri direttamente `index.html` nel browser — nessun server necessario.
